# Gram Stain Colour & Shape Reader

Educational client-side Gram stain colour and bacterial morphology reader.

## Netlify
Drag the project folder into Netlify. No build command is required.

## GitHub Pages
Upload all files to a repository, then enable Settings → Pages → Deploy from branch.

## Important
The image algorithms are simple educational heuristics, not validated clinical AI. They cannot identify a bacterial species or diagnose infection.
